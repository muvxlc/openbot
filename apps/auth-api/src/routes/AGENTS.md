## CONVENTIONS
- TanStack Solid Router: Routes define `export const Route = createFileRoute(path)({ server: { handlers: ... } })`.
- File naming escapes: Literal periods in filenames must use square brackets (e.g. `[.]well-known`, `sitemap[.]xml.ts`).
- Dynamic segments: Prefix dynamic path parameters with `$` (e.g. `$platform.tsx`, `$slug.tsx`, `$hostId/index.ts`).
- SSR runtime boundary: Handlers dynamically import `cloudflare:workers` inside server handler functions to keep browser bundles clean.
- Client lazy splitting: Use `.lazy.tsx` for client-only UI components deferred after initial load.

## ANTI-PATTERNS
- Never bundle `cloudflare:workers` into browser bundles (keep imports scoped inside server handlers).
- Never execute client-only UI libraries (e.g. canvas or animation engines) in workerd SSR runtime.
- Never edit `apps/auth-api/src/lib/plugin-catalog.generated.ts` directly; generated by build tooling.
- Never proxy unverified external icon URLs directly without host origin controls (`plugins.ts`).
- Never let client analytics exceptions throw or interrupt landing page rendering (`analytics.ts`).
